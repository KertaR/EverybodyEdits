Quick Server Features & Controls

  • World Files: Saved automatically as JSON inside server/worlds/
  • Commands & Controls:
    • Arrow keys / WASD: Move player
    • Number keys / Palette: Place blocks
    • Godmode toggle, chat, world saving enabled
